### 🔧 FEATURE TOGGLES - ENABLE/DISABLE:

# BASIC CHAT SETTINGS
global.private = true;       ✅ Allows bot to work in private chats (1-on-1)
global.group = true;         ✅ Allows bot to work in group chats
global.welcome = true;       ✅ Sends welcome message when users join groups
global.autoread = true;      ✅ Automatically marks messages as "read"

# SECURITY & PROTECTION
global.anticall = true;      ✅ Blocks users who call the bot (auto-unblocks after 5min)
global.audioblock = true;    ✅ Blocks users who send voice notes (5min block)
global.stickerBlock = true;  ✅ Blocks users who send stickers (5min block)
global.antilink = true;      ✅ Deletes WhatsApp group links from chats
global.blockDM = false;      ❌ Allows direct messages (set true to block)

global.autoreact = true;    ✅ Auto-reacts to messages (true = enable)
global.likestatus = true;    ✅ Auto-likes status updates
global.chatbot = true;       ✅ AI responds to normal messages (not commands)
global.savestatus = true;    ✅ Saves status updates to your DM

## ⚠️ IMPORTANT NOTES:

✅ TRUE = Feature is ACTIVE/ENABLED
❌ FALSE = Feature is DISABLED/OFF

Example:
global.antilink = true;   = Bot will delete group links
global.antilink = false;  = Bot will ignore group links

## 🔧 HOW TO MODIFY:

1. Open config.js file
2. Find the setting you want to change
3. Change true/false value
4. Save the file
5. Bot auto-reloads changes

Example change:
FROM: global.chatbot = true;
TO:   global.chatbot = false;  // Disables AI responses

## 🛠️ TROUBLESHOOTING:

Problem: Bot not responding in groups
Solution: Set global.group = true;

Problem: Bot blocking voice notes
Solution: Set global.audioblock = false;

Problem: Bot not working in private chat
Solution: Set global.private = true;

Problem: Too many automated messages
Solution: Disable chatbot, autoreact, likestatus
